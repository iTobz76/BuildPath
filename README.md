# SwiftPath
Learn to code by building. An iOS app with bite-sized Swift and Python lessons that each end with something you actually made.

A Mimo (mimo.org) inspired iOS app for learning Swift and Python through short, interactive lessons: gap-fills, reordering, bug fixing and writing code. Every course builds toward a real project. Built with SwiftUI and xtool in WSL (Windows Subsystem for Linux).
