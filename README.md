# SwiftPath

Report bugs here: https://forms.gle/Wzxu3opFRrytVQYj6

Learn to code by building. An iOS and PWA app with bite-sized Swift and Python lessons that each end with something you actually made.

A Mimo (mimo.org) inspired iOS/PWA app for learning Swift and Python through short, interactive lessons: gap-fills, reordering, bug fixing and writing code. Every course builds toward a real project. Built with SwiftUI and xtool in WSL (Windows Subsystem for Linux) and HTML.

Logins are powered by **Cloudflare** (https://github.com/cloudflare) and **PocketBase** (https://github.com/pocketbase)
